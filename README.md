
# Portfolio — David Cruz

This repository is a frontend portfolio that showcases practical web projects and coding standards relevant to junior/mid frontend roles. It highlights responsive design, semantic HTML, approachable CSS, and lightweight JavaScript.

Quick summary: clean, static portfolio built with modern best practices to demonstrate front-end fundamentals to recruiters and hiring managers.

## Technologies

- HTML5 (semantic markup)
- CSS3 (responsive layout, modular styles)
- JavaScript (vanilla, small interactive features)

Project structure:

- `index.html` — main entry
- `CSS/` — styles
- `JS/` — scripts
- `imagens/` — assets

## Demo

Open `index.html` in any modern browser or host the folder with a simple HTTP server. If deployed, include the public URL here.

## Key highlights for recruiters

- Responsive layout and mobile-first approach
- Clear semantic HTML and accessibility considerations
- Small, focused JavaScript for interaction without heavy frameworks
- Organized assets and CSS structure suitable for scaling
- Clean commit history and concise changelog entries

## How to run locally

1. Clone the repository.
2. Open `index.html` in a browser, or run a simple static server, for example with Python:

```bash
python -m http.server 8000
# then open http://localhost:8000
```
